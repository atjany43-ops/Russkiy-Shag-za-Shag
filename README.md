# Русский шаг за шагом

**Учите русский легко и с удовольствием!**

Мобильное приложение для изучения русского языка для начинающих иностранных студентов. В первой версии: общеупотребительные слова и их произношение.

## Структура проекта

| Папка | Содержимое |
|-------|-----------|
| `01_Описание_системы/` | Описание функционала системы |
| `02_Функциональные_требования/` | Функциональные требования |
| `03_UML_диаграммы/` | Диаграммы UML (файлы .puml) |
| `04_Дизайн/` | Логотип, эскизы экранов и форм, элементы управления |
| `05_Анализ_аналогов/` | Анализ аналогов: Duolingo, Busuu, Memrise |
| `06_Исходный_код/` | Код приложения (позже) |
